# The pixel-universality transmission (David, 2026-09-08)

Captured without interference; governs the reproduction programme's
long arc.

## Why the porting exists
The legacy pipeline was Keynote exported into Final Cut Pro, with
manual transitions and edits added there — which is WHY the artifacts
are messy and non-uniform (a version-controlled set of messy files
with manual steps on top). The goal is ONE unified framework where
everything is instantaneous, wireless, real time — a version-
controlled DreamSong instead.

## The ladder toward universality
1. **Deep context (now, welcome)**: decks, source repos, assets — use
   them, and keep recording how to handle each kind encountered.
2. **Partial context**: e.g. 3Blue1Brown's open-sourced source files —
   backward-looking, legacy content made interactive. Navigate
   attribution carefully (never look like stealing; he open-sources
   some videos' sources). The prime example: the Fourier-transform
   video (SVG inputs → Fourier decomposition of complex-valued
   functions) — the SVG lives in his repo; extract and use it.
3. **Pixels only — THE JUMP TO UNIVERSALITY**: a video and nothing
   else, recreated from vision alone (the way cutting-edge models
   recreate a Blender scene from photos of a house). The DreamTalk
   skill should offer this as a mode: throw in a video, let an agent
   run until it has reproduced it flawlessly. Not possible for every
   video; possible for many.

## The holonic recognizer
Going forward, the leverage is identifying objects/holons WITHIN any
scene: if a symbol keeps recurring, create it ONCE — the holonic
architecture lets recognition disassemble complexity, so individual
objects get reproduced faithfully in isolation from the rest. This
will crystallize over time.

## Operational consequences (immediate)
- MP4 renders are NOT part of the reproduction loop — evaluation is
  frame-selective against the live scene (the gauntlets' native
  mode). No full renders unless David asks. (The 1.5h "render" was
  never rendering — it was per-frame GPU readback + PNG encode +
  disk; the renderer itself is real time.)
- Forward-facing framing: a more powerful way to create content;
  backward-facing: legacy content made interactive.
