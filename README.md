# DreamTalk

![](DreamTalk.gif)

> **At a glance (for engineers):** A recursive parametric animation
> framework in TypeScript on WebGPU — platonic symbols whose source code
> IS the thing, not a representation of it. A pure-timeline core (every
> frame is a function of `t` — scrubbing, rendering, and testing all
> sample the same math), TSL/WebGPU stroke rendering with an exact
> ink-width contract, a Keynote-inspired editor with bidirectional
> UI↔code editing, and a machine-verified reproduction pipeline that
> scores renders against reference footage to sub-pixel chamfer.
> Holarchic architecture: symbols compose to arbitrary depth as git
> submodules. TypeScript · three.js/WebGPU · Bun. 500+ tests.
> The 2023–2025 Python/Cinema 4D library remains in-repo as the
> authoring backend and prior art.

## Philosophical Meaning

DreamTalk extends the ancient indigenous modality of SandTalk,
popularised through [Tyson Yunkaporta's book](https://www.amazon.com/Sand-Talk-Indigenous-Thinking-World/dp/0062975641),
into the digital domain.

SandTalk's constraints (symbols must be drawable in sand during campfire
conversation):
- Line based
- Two dimensional
- No colouring, shading, or movement

DreamTalk expands these principles while retaining their essence:
- Line based (strokes, splines)
- Two and three dimensional
- Basic colouring and shading
- Animations allowed

Photorealistic images or painterly styles are outside this class. A
flower of life generated by a diffusion model might *look* correct, but
it isn't actually nineteen interlocking circles with precise geometric
relationships. DreamTalk constructs the mathematical truth — and the
construction travels with the symbol.

## Proof by Reproduction

The framework is validated by faithfully reproducing existing work and
measuring the result, frame by frame, against the original footage:

- **[Dialectical Thinking (2021) — side by side](docs/reports/video01/DialecticalThinking-sidebyside.mp4)** —
  the full 151-second film as one composite timeline, ten scenes, next
  to the original render with its soundtrack.
- **[TheWall — side by side](docs/reports/wall/TheWall-sidebyside.mp4)** —
  236 creatures flying Bezier journeys into a circular wall, each
  trailing a physically simulated cable baked to a pure function of
  time: 0.93 mean coverage at 0.86px chamfer against the original.

Where the reproduction beats its reference (a hand-drawn bezier
approximating a circle, a render artifact of a zero-scaled clone), the
difference is documented rather than imitated —
[docs/FIDELITY-LEDGER.md](docs/FIDELITY-LEDGER.md) maps every place
fidelity and the ideal diverge, and new work always defaults to the
ideal.

## The Editor

A Keynote × Cinema 4D × manim hybrid, running live on the same core:
scene rail, click-to-select with a holarchy outline, an inspector showing
exactly the promoted parameters, a duration-based timeline (no keyframe
lanes), reference footage as a timeline-synced backdrop overlay — and a
camera you can grab: pause any scene, fly around it, press play, and the
view glides back to the authored perspective. Everything you change in
the UI is written back into the source file; the file is the only truth.

## Quickstart

```bash
git clone https://github.com/ProjectLiminality/DreamTalk.git
cd DreamTalk/core
bun install
bun scripts/daemon.ts        # → http://localhost:4174/?scene=s01
```

Scenes are TypeScript classes:

```ts
class MolochEyeScene extends Dream {
  eye = new MolochEye({ height: 300 })
  unfold() {
    this.play(Create(this.eye), 3)
  }
}
```

Every proportion in that symbol is a derivation, not a decimal — the
eye's lens is a 3-4-5 arc construction, its pupil a true cube in
one-point perspective whose stroke widths follow the same projection.

## The Larger Vision

DreamTalk is the symbol-creation instrument of the
[DreamOS](https://github.com/ProjectLiminality) ecosystem, where
knowledge lives as git repositories called **DreamNodes**. Every
DreamNode presents itself through a **DreamTalk symbol** (its exterior
face — how it appears in space) and explains itself through
**DreamSongs** (its interior perspective — orchestrated plays of the
ideas it contains). Symbols compose into songs, songs into worlds; a
video is just a constrained traversal of a living scene you can pause
and step into. The tool will eventually author itself: most UI is a 2D
scene, and the editor is on the path to becoming a DreamSong rendered
by the framework it edits.
